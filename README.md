# examples

The repository demonstrates how to use [FunctionalScript](https://github.com/functionalscript/functionalscript) as an npm package.

## Run Locally

**Prerequisites** [Node.js](https://nodejs.org/) version 22 or higher.

1. Install dependencies:
   ```sh
   npm ci
   ```
2. Run the server
   ```sh
   npm run web
   ```
3. Open [http://localhost:3000](http://localhost:3000)

To run the tests:

```sh
npm test
```
